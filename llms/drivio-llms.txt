# Drivio

> Drivio (Drivio Technologies Pvt Ltd) is a tech-enabled, omni-channel two-wheeler financing marketplace in India that connects motorcycle, scooter, and electric-vehicle buyers with banks and NBFCs. Founded in 2022 and backed by 500 Global, it offers EMI calculators, instant eligibility checks, finance offers, vehicle comparison, and same-day loan approval and disbursal. Drivio is an ISO/IEC 27001 certified company. Drivio publishes no public API or developer program; this profile is an API Evangelist network catalog entry.
